# Security Policy

Please do not report security vulnerabilities in public issues or pull requests.

Send a private report to [mostafa.moradipoor73@gmail.com](mailto:mostafa.moradipoor73@gmail.com) with a description, affected files or versions, and steps to reproduce. Redact camera addresses, credentials, personally identifying video, and proprietary model details. Please allow reasonable time for review before public disclosure.

No supported release schedule is currently published.
