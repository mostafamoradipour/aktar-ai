# Contributing

Contributions to Aktar AI are welcome.

## Before you start

- Open an issue to discuss substantial changes to the processing pipeline or configuration format.
- For bug reports, include the command, relevant configuration keys, dependency/runtime versions, and a concise log excerpt.
- Replace stream URLs, broker addresses, model paths, and calibration data with safe placeholders before sharing examples.

## Development workflow

1. Fork the repository and create a branch for your change.
2. Make a focused change and update `README.md` or configuration examples when behavior changes.
3. Run the relevant checks available for the changed code and state the exact commands and environment in your pull request.
4. Open a pull request describing the behavior, operational impact, validation, and any model or hardware requirements.

Never commit credentials, private camera endpoints, proprietary model weights, or deployment-specific calibration files.
